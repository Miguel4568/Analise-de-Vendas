# Análise de Vendas

## Sobre o projeto
Projeto de análise de dados de vendas de uma loja,
utilizando Python e Pandas.

## Tecnologias utilizadas
- Python
- Pandas
- Matplotlib
- Flask
- HTML
- CSS
- JavaScript

## Funcionalidades
- Análise de faturamento
- Produtos mais vendidos
- Vendas por período
- Gráficos estatísticos
- Dashboard interativo

## Como executar

1. Clone o repositório.
2. Instale as dependências:
```bash
pip install -r requirements.txt
```
3. Execute o projeto:
```bash
python app.py
```
